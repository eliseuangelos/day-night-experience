Use em seu site

Importe o tema padrão direto do repositório, sem baixar nem enviar arquivos para outro repositório. Cole no HTML do seu site:

<!-- no <head>, antes do CSS do seu site (evita o "flash" de tema) -->
<script src="https://eliseuangelos.github.io/day-night-experience/assets/js/theme-init.js"></script>
<link rel="stylesheet" href="https://eliseuangelos.github.io/day-night-experience/component/day-night.css">

<!-- antes de </body> -->
<script src="https://eliseuangelos.github.io/day-night-experience/component/day-night.js"></script>
<script>DayNight.init({ position: 'top-right' });</script>
Prefere um CDN? Use o jsDelivr 
<!-- no <head>, antes do CSS do seu site (evita o "flash" de tema) -->
<script src="https://cdn.jsdelivr.net/gh/eliseuangelos/day-night-experience@main/assets/js/theme-init.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/eliseuangelos/day-night-experience@main/component/day-night.css">

<!-- antes de </body> -->
<script src="https://cdn.jsdelivr.net/gh/eliseuangelos/day-night-experience@main/component/day-night.js"></script>
<script>DayNight.init({ position: 'top-right' });</script>

O @main entrega sempre a versão mais recente do repositório. Para travar uma versão, troque por uma tag, como @v1.3.0 (crie a tag em Releases).

Baixar ou clonar o repositório 
git clone https://github.com/eliseuangelos/day-night-experience.git

Ou baixe o ZIP e copie component/day-night.js e component/day-night.css para o seu projeto.
